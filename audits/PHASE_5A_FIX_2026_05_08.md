## What Shipped

- `Models/DailyInsight.swift`
  - `InsightKind` (7-case enum, rawValue mapping to web's TS union: `budget_pacing`, `category_trend`, `goal_nudge`, `streak_boost`, `subscription_alert`, `reflection`, `quick_win`)

### Service
- `Services/DailyInsightService.swift`
  - `fetchToday(userId:)` — direct Supabase SELECT scoped by `(user_id, insight_date = today)`
  - `dismissToday(userId:)` — direct Supabase UPDATE setting `dismissed_at` to ISO8601-now

### Utility
- `Utilities/InsightSymbol.swift` — Lucide name → SF Symbol mapping
  - 8 known mappings: TrendingUp / Flame / Eye / Target / Sparkles / ArrowRight / Zap / RefreshCw
  - `sparkles` fallback for unknown names

### State
- `AppState.dailyInsight: DailyInsightRow?` (private(set))
- Service injection with default no-arg init
- Parallel fetch in `loadProfile` AND `refreshHomeData` — sets `dailyInsight = nil` when row is missing OR `dismissed_at` is set
- `dismissDailyInsight()` — optimistic clear, fire-and-forget UPDATE, no rollback

### Component
- `Features/Home/Components/DailyInsightBanner.swift`
  - Accent-tinted border (20% opacity) + faint glow shadow (6%)
  - Leading SF Symbol icon (16pt)
  - Headline (14pt semibold) + body (12pt muted) + optional accent-colored stat row
  - Trailing X dismiss button

### Wiring
- `Features/Home/AuthenticatedHomeView.swift` — banner slot between `CycleNavRow` and `CycleCard`, conditional on `appState.dailyInsight != nil`, slide+fade on dismiss

## Locked architectural decisions

- Direct Supabase access (NOT HTTP via Next.js routes)
- Lucide → SF Symbol via static dictionary
- DailyInsightBanner is standalone (NOT a HintCard subclass)
- Optimistic dismiss with no rollback (matches web)
- Per-day semantics: dismissing today's row only hides today; tomorrow's cron generates a fresh un-dismissed row
- Strict 7-case `InsightKind` enum (matches web exactly); future AI kind additions require an iOS update

## Adaptations from the prompt's templates

The prompt's templates assumed a service pattern that doesn't match the existing iOS codebase. Same adaptations as Phase 4:

- `actor DailyInsightService { static let shared = ... (client: PostgrestClient) }` → `final class DailyInsightService { private var client: SupabaseClient { SupabaseManager.shared.client } }` with default no-arg init.
- `appState.currentUserId` → `appState.session?.user.id` (no `currentUserId` property exists; user UUID is on `session.user.id`).
- `.is("dismissed_at", value: "null")` safety guard on UPDATE: dropped per the prompt's note. The `(user_id, insight_date)` composite uniquely identifies today's row, so overwriting an already-dismissed row's timestamp is harmless.

## Behavioral notes

- **First sign-in / refresh**: parallel fetch resolves; if a row exists with `dismissed_at == nil`, banner appears.
- **No row for today**: cron hasn't run, or skipped for this user → `dailyInsight` stays nil → no banner, no skeleton, no error.
- **Already-dismissed row**: AppState filters at the boundary (`dismissedAt != nil ? nil : row`) → banner doesn't appear.
- **Dismissing**: optimistic `dailyInsight = nil`; banner slides up + fades out; UPDATE fires in background; failures silently logged in DEBUG.
- **Cross-platform consistency**: dismissing on iOS persists to web instantly via Supabase; web's InsightStrip respects the same `dismissed_at` field.
- **Pull-to-refresh** also re-fetches the insight, so a freshly-generated row (e.g. via web's `/api/insights/trigger-for-me`) appears without app restart.

## Color mapping rationale

`InsightAccent → SwiftUI.Color`:

| Accent | Source | Token |
|---|---|---|
| `green` | web `text-[#D4A017]` (gold) | `SikaTheme.Color.sikaAccent` |
| `amber` | `#FBBF24` | `SikaTheme.Color.sikaWarning` |
| `red` | `#F87171` (lighter than `.destructive` which is `#F43F5E`) | `Color(hex: 0xF87171)` |
| `blue` | `#60A5FA` | `SikaTheme.Color.bucketSavings` |
| `neutral` | muted text | `SikaTheme.Color.mutedForeground` |

`green → gold` looks counterintuitive but matches web — see `ACCENT_STYLES.green = { text: 'text-[#D4A017]' }` in web's `insight-strip.tsx`. The product treats green-positive insights with a gold-positive treatment.
